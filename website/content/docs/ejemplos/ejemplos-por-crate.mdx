Además del proyecto `example/rust`, cada crate trae ejemplos propios en su
carpeta `examples/`. Ninguno se conecta a SUNAT: usan transportes simulados o
datos sintéticos, así que se pueden ejecutar en cualquier momento desde la raíz
del repositorio.

| Crate | Ejemplo | Qué muestra | Página |
| --- | --- | --- | --- |
| `cpeforge` | `fachadas_sin_red` | `See` y `Api` con un transporte simulado | [cpeforge](/docs/paquetes/cpeforge#ejemplo-sin-red) |
| `cpeforge` | `importe_en_letras` | La leyenda 1000 | [Importe en letras](/docs/conceptos/importe-en-letras) |
| `cpeforge` | `see_with_xcodes` | El catálogo de códigos conectado a `See` (feature `xcodes`) | [cpeforge-xcodes](/docs/paquetes/xcodes) |

## Ejecutarlos

```bash
cargo run -p <crate> --example <ejemplo>
```

Por ejemplo:

```bash
cargo run -p cpeforge-xml --example invoice_xml
cargo run -p cpeforge-report --example invoice_html > factura.html
cargo run -p cpeforge --example see_with_xcodes --features xcodes
```

`cpeforge-ubl-validator` y `cpeforge-cpe-validator` necesitan libxml2 y libxslt.
Ver [Requisitos](/docs/primeros-pasos/requisitos).
