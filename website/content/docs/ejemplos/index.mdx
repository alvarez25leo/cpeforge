El proyecto [`example/rust`](/docs/primeros-pasos/ejecutar-los-ejemplos)
construye, firma y envía 48 comprobantes a los entornos de prueba de SUNAT.
Todos fueron aceptados por SUNAT beta, salvo `factura-beatose`, que solo genera
el XML.

Busca por nombre o por tema (por ejemplo, «detracción», «crédito» o «dólares»)
y abre la **guía** para ver el caso explicado con su código, o el **código** para
verlo en GitHub.

<EjemplosExplorer />

## Ejecutar un caso

```bash
cargo run --release --manifest-path example/rust/Cargo.toml -- factura-credito            # genera el XML firmado
cargo run --release --manifest-path example/rust/Cargo.toml -- --enviar factura-credito   # y lo envía a SUNAT beta
```

El XML firmado queda en `example/rust/out/`. Ver
[Ejecutar los ejemplos](/docs/primeros-pasos/ejecutar-los-ejemplos) para las
credenciales y las variables de entorno.
