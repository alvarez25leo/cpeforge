El repositorio incluye un proyecto completo,
[`example/rust`](https://github.com/alvarez25leo/cpeforge/tree/main/example/rust),
que construye, firma y (opcionalmente) envía **48 comprobantes**, más 4 casos
de rechazo deliberado. Todos usan entornos de prueba y credenciales públicas.

## Clonar y ejecutar

```bash
git clone https://github.com/alvarez25leo/cpeforge.git
cd cpeforge
```

<Tabs items={['Solo generar', 'Generar y enviar', 'Casos de rechazo']}>
  <Tab value="Solo generar">
    Genera el XML firmado de todos los casos en `example/rust/out/`, sin red:

    ```bash
    cargo run --release --manifest-path example/rust/Cargo.toml
    ```

    O solo algunos casos:

    ```bash
    cargo run --release --manifest-path example/rust/Cargo.toml -- factura boleta
    ```
  </Tab>
  <Tab value="Generar y enviar">
    Además los envía a SUNAT beta (o a la API de guías de prueba) y muestra la
    respuesta:

    ```bash
    cargo run --release --manifest-path example/rust/Cargo.toml -- --enviar factura
    ```
  </Tab>
  <Tab value="Casos de rechazo">
    Genera los casos que SUNAT debe rechazar, en `out/errores/`:

    ```bash
    cargo run --release --manifest-path example/rust/Cargo.toml -- --errores
    ```
  </Tab>
</Tabs>

Cada XML se verifica con el certificado que lleva incluido antes de enviarlo.

- `src/casos/<caso>.rs`: un archivo por comprobante.
- `src/datos.rs`: los datos compartidos (empresa, cliente y fecha base).
- `src/config.rs`: lee las credenciales y crea las fachadas `See` y `Api`.
- `src/errores.rs`: los casos de rechazo.

## Los casos

Los 48 casos (25 facturas, 3 boletas, 4 notas, resúmenes, bajas, reversiones,
retención, percepción, liquidaciones de compra y guías de remisión) están en el
[explorador de ejemplos](/docs/ejemplos), con buscador y enlace a la guía que
explica cada uno.

`factura-beatose` solo genera XML: su demo original apunta a un servidor de
terceros.

Con `--errores` se generan además cuatro
[casos de rechazo](/docs/ejemplos/casos-de-rechazo) con un error deliberado.

## Variables de entorno

| Variable | Para qué sirve | Por defecto |
| --- | --- | --- |
| `EJEMPLO_CREDENCIALES` | JSON con tus propias credenciales de prueba | `example/credenciales/credenciales-prueba.json` |
| `EJEMPLO_CERT` | Otro certificado PEM | El que indica el JSON |
| `EJEMPLO_FECHA` | Fecha base fija (`AAAA-MM-DD HH:MM:SS`, hora de Lima) | La hora actual |
| `EJEMPLO_PAUSA` | Segundos entre envíos (SUNAT beta responde 401 si son muy seguidos) | `5` |
| `EJEMPLO_REPETICIONES` | Llamadas por fase al medir el rendimiento | `10` |

Con la misma `EJEMPLO_FECHA`, el XML firmado es reproducible byte a byte.

El JSON de credenciales tiene esta forma (la sección `gre` es opcional; sin
ella, las guías solo generan XML):

```json title="credenciales.json"
{
  "certificado": "mi-certificado.pem",
  "sunat_beta": { "ruc": "…", "usuario": "…", "clave": "…" },
  "gre": {
    "api_url": "…", "client_id": "…", "client_secret": "…",
    "ruc": "…", "usuario": "…", "clave": "…"
  }
}
```

<Callout type="warn" title="Solo entornos de prueba">
  El proyecto rechaza una URL de producción de SUNAT. Para usar tus propias
  credenciales de prueba, apunta `EJEMPLO_CREDENCIALES` a un archivo fuera del
  repositorio.
</Callout>

## Rendimiento

Cada ejecución mide cada caso por fases (construir, XML, firma, XML firmado,
primera llamada y, con `--enviar`, envío y estado) y deja los resultados en
`example/rust/out/benchmark.json`. Compila en `--release` para medir. Ver
[Rendimiento](/docs/introduccion/rendimiento).

## Los ejemplos de cada crate

Cada crate trae sus propios ejemplos, que se ejecutan sin red:

```bash
cargo run -p cpeforge --example importe_en_letras
cargo run -p cpeforge --example fachadas_sin_red
cargo run -p cpeforge --example see_with_xcodes --features xcodes
cargo run -p cpeforge-core --example invoice_model
cargo run -p cpeforge-xml --example invoice_xml
cargo run -p cpeforge-xmldsig --example sign_verify_invoice
cargo run -p cpeforge-ws --example local_cdr
cargo run -p cpeforge-report --example invoice_html
cargo run -p cpeforge-xml-parser --example parse_invoice
```
