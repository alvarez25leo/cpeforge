## Generar la referencia en local

Desde la raíz del repositorio:

```bash
cargo doc --workspace --no-deps --all-features --open
```

La CI genera la documentación con `RUSTDOCFLAGS="-D warnings"`, así que un
enlace roto en la documentación hace fallar la compilación. Además, el lint
`missing_docs` y `clippy -D warnings` obligan a documentar todo elemento
público.
